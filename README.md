**Webphone Safe Call**

**Описание**
При исходящих звонках в Webphone Наумен в начале раздаются громкие
технические сигналы, которые нельзя отключить. Расширение добавляет
кнопку «Позвонить не оглохнув» — она выключает звук на 4.5 секунды, защищая
слух и хорошее настроение менеджера, а затем возвращает громкость.

**Как установить**
1. Скачайте и распакуйте расширение в любую папку.
2. Откройте Chrome и перейдите на страницу расширений:
chrome://extensions/
3. Включите «Режим разработчика» (Developer mode) – переключатель в правом
верхнем углу.
4. Нажмите кнопку «Загрузить распакованное расширение» (Load unpacked).
5. Выберите папку с расширением и нажмите «Выбрать папку».
6. Расширение установится и сразу начнёт работать.

**Как пользоваться**
1. Откройте вкладку Webphone:
https://yclients.nau.team:8443/webphone
2. Нажмите на иконку номеронабирателя телефона слева, чтобы открыть
модальное окно набора номера.
3. Внизу клавиатуры появится кнопка «Позвонить не оглохнув».
4. Наберите номер и нажмите эту кнопку вместо обычной «Позвонить».
5. Что произойдёт: Звук во вкладке мгновенно выключится, а Наумен начнёт звонить;
Через 4.5 секунды звук включится обратно. В правом верхнем углу будет индикатор уровня звука.

**Как удалить**
На странице chrome://extensions/ нажмите «Удалить» у карточки расширения.

**Примечание**
Расширение работает только на закладке с Науменом: yclients.nau.team:8443 и не
влияет на другие вкладки. Никаких настроек не требуется – просто установите и
пользуйтесь. Расширение не собирает, не обрабатывает и не передаёт никакие
данные.
